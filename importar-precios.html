Importar lista de precios

Sube el Excel o CSV de un proveedor nacional y carga todos los productos de una vez, con el margen ya calculado para cada uno.

1. Elige el proveedor y el margen a aplicar

2. Sube el archivo (.xlsx o .csv)

Haz clic para elegir el archivo, o arrástralo aquí
El archivo debe tener una columna con el nombre del producto y otra con el costo en USD. Nombres de columna aceptados: "nombre" / "producto" / "descripcion" para el producto, y "costo" / "precio" / "costo_usd" para el precio. Opcional: una columna "categoria".

3. Revisa antes de cargar
