Importar lista de precios

Sube el Excel o CSV de un proveedor nacional y carga todos los productos de una vez, con su costo ya cargado. El margen de ganancia y la comisión de Mercado Libre se definen después, producto por producto, desde el Dashboard (así cada uno puede llevar un margen distinto) — hasta que no se definan ahí, el producto queda guardado como borrador: sin precio y sin publicarse en el catálogo.

Esta herramienta trabaja con costos de proveedor, así que solo está disponible para el rol dueño. Si necesitas cargar productos nuevos sin precio, pídele a un dueño que lo haga desde aquí, o cárgalos manualmente desde Productos.

1. Elige el proveedor

2. Sube el archivo (.xlsx, .csv o .pdf)

Haz clic para elegir el archivo, o arrástralo aquí
El archivo debe tener una columna con el nombre del producto y otra con el costo en USD. Opcionalmente también reconoce columnas de código/SKU, marca, categoría y descripción — en el siguiente paso confirmas cuál es cuál, sin importar cómo las haya nombrado el proveedor. Si una variante/modelo no tiene precio del proveedor (por ejemplo "no disponible"), no se importa — pero si comparte descripción con otras variantes que sí tienen precio, esas sí la conservan completa. Para PDF: debe tener texto seleccionable y una tabla de precios clara — no funciona con PDFs escaneados como imagen.

3. Confirma qué columna es cuál

Detectamos estas columnas en tu archivo. Indica cuál corresponde a cada dato — así funciona sin importar cómo las haya nombrado el proveedor.
Si el proveedor la trae, se guarda para poder ver y filtrar por stock en el Dashboard — así sabes antes de publicar en Mercado Libre si de verdad hay existencia.
Si el archivo no trae una columna de categoría, o la deja vacía en algunas filas, el sistema intenta clasificar el producto automáticamente (laptop, desktop, UPS, cámaras, accesorios, etc.) a partir del nombre y la descripción — puedes corregirla fila por fila en la vista previa antes de cargar.
