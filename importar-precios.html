Importar lista de precios

Sube el Excel o CSV de un proveedor nacional y carga todos los productos de una vez, con el margen ya calculado para cada uno.

1. Elige el proveedor y la ganancia a aplicar

2. Sube el archivo (.xlsx o .csv)

Haz clic para elegir el archivo, o arrástralo aquí
El archivo debe tener una columna con el nombre del producto y otra con el costo en USD. Opcionalmente también reconoce columnas de código/SKU, marca y categoría — en el siguiente paso confirmas cuál es cuál, sin importar cómo las haya nombrado el proveedor.

3. Confirma qué columna es cuál
